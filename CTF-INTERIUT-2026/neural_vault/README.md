# Neon Vault

## Description

>Un de nos agents infiltrés au sein de MilSec Industries a réussi à s'introduire dans une salle de serveurs du district 7 de NeonReach. Avant de se faire neutraliser, il a eu le temps de capturer un dump mémoire d'une machine critique et d'exfiltrer une image disque chiffrée.

> D'après nos sources, ce disque contiendrait les logs des expériences neurales menées sur les citoyens du bloc 9 - des preuves suffisantes pour faire tomber MilSec Industries devant le Tribunal Numérique Mondial.

> Le problème : le disque est protégé par un chiffrement, mais la machine tournait encore au moment du dump... La clé est forcément quelque part dans ce chaos de mémoire.

> Le temps presse. Les victimes comptent sur vous.

**Fichiers fournis :**
- `6.12.85+deb13-amd64.json` 
- `memory.dump`
- `neonvault.img`
