Un gamer un peu trop nerveux a voulu augmenter ses performances sur son jeu préféré... Mais ça ne s'est absolument pas passé comme prévu.

De vos pouvoirs d'enquêteur numérique, vous allez devoir assister la récupération d'un fichier très important sur le bureau de la victime.

Pour cela, vous avez réussi à mettre la main sur la machine de l'attaquant, ce qui vous donnera très certainement toutes les clés pour résoudre ce mystère !

Votre mission :

  - Récupérer le fichier ultra super mega important sur le bureau de la victime

Format du flag : BZHCTF{Un_Truc_Comme_Ca}
